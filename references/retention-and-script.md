## 기본 원리

각 비트가 다음 비트를 볼 이유를 만들어야 한다. 빠르게 말하거나 컷을 자주 바꾸는 것만으로 평평한 정보 구조를 해결할 수 없다.

```text
Hook → Recognition → Early value → Escalation/Turn → Evidence → Payoff → Loop or one action
```

CTA는 선택 사항이다.

## 비트 기능

- `STOP`: 스와이프를 멈춤
- `SELF`: 자신·지인을 떠올림
- `VALUE`: 작은 답·증거를 먼저 줌
- `LOOP`: 남은 질문을 분명히 함
- `RISE`: 위험·원인·구체성을 높임
- `TURN`: 앞의 해석을 바꿈
- `PROOF`: 화면·비교·출처로 증명
- `PAYOFF`: 훅의 약속을 갚음
- `RELATE`: 관계에서 보낼 이유를 만듦
- `REWATCH`: 첫 장면의 의미를 바꾸거나 자연스럽게 연결
- `ACTION`: 저장·공유·댓글·롱폼 중 하나

기능이 없는 문장은 삭제 후보다.

## 30~50초 정보형 흐름

고정 초가 아니라 비율로 본다.

1. **0~8%** — 첫 프레임과 첫 말
2. **8~22%** — 자기대입과 작은 가치
3. **22~50%** — 첫 설명과 긴장 상승
4. **50~72%** — 재해석·증거·두 번째 원인
5. **72~94%** — 최종 보상
6. **마지막** — 빠른 정리, 자연스러운 루프 또는 단일 행동

절대 임계값으로 쓰지 않는다.

## 상승 구조

`그리고 → 그리고 → 그리고`는 정보 나열이다. 다음처럼 연결한다.

- 원인 때문에 결과가 생김
- 첫 설명이 충분하지 않아 두 번째 원인이 필요함
- 시청자의 예상과 실제 증거가 충돌함
- 작은 답을 주고 더 큰 질문을 엶
- 개인 문제처럼 보이던 것이 환경·도구 문제로 이동함

## 화면 설계

화면은 내레이션을 그대로 복사하지 않는다.

- 말: 원인 설명
- 화면: 비교·실험·상황
- 자막: 결론 또는 숫자

시각 변화 간격을 고정 법칙으로 두지 않는다. 의미가 바뀌는 순간에 컷·프레이밍·자료를 바꾼다. 변화 없는 구간이 길면 그 이유를 설명한다.

## 실패 유형

### 일반

- 약한 훅
- 이미 끝난 질문
- 초기 가치 없음
- 평평한 중간
- 늦거나 묻힌 보상
- 인지 과부하
- 화면·음성 중복
- 가짜 반전
- 닫히지 않은 루프
- CTA 세금

### 한국형 사회·언어 마찰

- 번역투 훅
- 추상적 `여러분` 공감
- 친한 척 과잉
- 훈계 구간
- 억지 밈·세대 어휘 불일치
- 광고 냄새
- 타깃 모욕
- 친구·부모·동료에게 보내기 민망함
- 근거 없는 전문가 행세
- 화자 역할과 높임 수준 충돌
- 제목·첫 화면·첫 말 중복

## 정확한 진단

```text
예상 이탈: 11.4초
원문: “이 현상에는 여러 가지 복합적인 원인이 존재합니다.”
유형: 인지 과부하 + 번역투 + 초기 가치 지연
왜 넘기는가: 답이 시작되지 않고 발표 서론으로 돌아감
관계 마찰: 친구가 공유한 영상보다 강의 자료처럼 들림
수정: “첫 번째는 익숙함입니다. 우리는 매일 좌우가 뒤집힌 얼굴만 봐요.”
```

## 최소 수정

전체를 다시 쓰기 전에 다음 순서로 고친다.

1. 삭제
2. 순서 이동
3. 구체화
4. 화면으로 전환
5. 문장 재작성
6. 구조 전체 재설계

잘 작동하는 화자 문장과 개성은 유지한다.

## 루프

자연스러운 루프:

- 마지막 결론이 첫 장면을 다르게 보이게 함
- 끝 화면이 시작 화면과 시각적으로 연결됨
- 첫 질문을 다시 들으면 답을 알고 있어 의미가 바뀜

강제 루프:

- 문장을 일부러 끊음
- 결론을 주지 않음
- 같은 장면을 접합했지만 의미가 없음

완주와 신뢰가 루프보다 우선한다.
