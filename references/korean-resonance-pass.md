## 1. Scene

- 첫 3초 안에 특정 장소·행동·결과가 보이는가?
- `누구나`, `많은 사람`, `현대인`을 실제 순간으로 바꿀 수 있는가?
- 제목을 몰라도 첫 화면과 첫 말만으로 맥락이 잡히는가?

교정:

- 추상: `많은 사람이 사진 때문에 자신감을 잃습니다.`
- 장면: `남이 찍어준 단체사진 확대해 보고 조용히 화면 끈 적 있죠?`

## 2. Relationship

- 제작자는 친구·선배·해설자·전문가 중 누구인가?
- 해당 호칭과 종결어미가 자연스러운가?
- 반말·존댓말을 섞지 않았는가?
- `~잖아요`로 동의를 강요하지 않는가?

## 3. Emotional Contract

주 보상을 하나만 고른다: 안도, 유용함, 놀람, 소속감, 안전한 논쟁, 웃음, 관점 전환.

훅이 약속한 감정과 끝의 감정이 맞는지 본다. 충격으로 열고 평범한 설명으로 끝내지 않는다.

## 4. Face Cost

다음 표현이 필요한지 묻는다.

- `당신은 틀렸습니다`
- `이것도 모르셨죠?`
- `요즘 애들은`, `아재라면`, `시니어들은`
- `정상인이라면`
- 외모·직업·학력·지역을 웃음의 대상으로 만드는 말

도발을 유지한다면 사람보다 통념·선택·구조에 긴장을 건다.

## 5. Share Scene

```text
보낼 사람:
붙일 한마디:
보내는 이유: 웃김 / 도움 / 안도 / 논쟁 / 기억 / 경고
```

비어 있으면 공유 CTA를 붙이지 않는다. 내용에서 보낼 이유를 먼저 만든다.

## 6. Title Functions

현재 국내 제목 관찰에서 반복되는 기능을 후보로만 활용한다.

1. 장면 → 결과: `[상황]하면 벌어지는 일`
2. 익숙한 대상 → 숨은 정보: `[대상]의 정체/이유`
3. 사람·역할 → 예상 밖 판단
4. 관계 → 행동
5. 비교 → 온도차
6. 실용 보상 → 간단한 기준·방법

- 제목이 실제 보상을 과장하지 않는가?
- 첫 화면이 제목을 다시 읽지 않고 새로운 정보를 주는가?
- 최근 인기 영상의 고유 문장을 복제하지 않았는가?

## 7. Spoken Korean

- 낭독해 숨이 막히는 문장을 자른다.
- 한 문장에 원인 하나만 둔다.
- 긴 한자어·영어 용어는 즉시 일상어로 풀이한다.
- 접속어는 실제 해석 변화가 있을 때만 쓴다.
- 감탄사·의성어가 사실을 대신하지 않는다.

## 8. Subtitle

- 첫 화면은 한 생각인가?
- 조사·어미가 다음 줄로 떨어지지 않는가?
- 소리 없이도 핵심 질문과 보상이 보이는가?
- 음성을 그대로 받아쓰지 않고 핵심 해석을 압축하는가?
- 작은 글씨로 정보 영상처럼 보이기만 하지는 않는가?

## 9. Audience Prior

- 연령 prior가 개인을 고정관념으로 만든 것은 아닌가?
- 실제 시청 순간과 진입 경로가 적혀 있는가?
- 필요한 신뢰 신호가 있는가?
- 타깃이 넓다면 유행어와 문화 전제의 비용을 줄였는가?

## 10. Evidence

- 최신 유행·플랫폼 기능·통계에 날짜와 출처가 있는가?
- 콘텐츠 제목 관찰을 알고리즘 법칙으로 바꾸지 않았는가?
- 외부 스킬의 성과 수치를 검증 없이 옮기지 않았는가?
- 사실·해석·사견·휴리스틱을 구분했는가?
