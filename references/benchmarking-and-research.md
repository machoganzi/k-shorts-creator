# 조사·벤치마크·출처 위계

## 날짜 범위

`최근 6개월`은 한국시간 기준 요청일에서 정확히 6개월 전부터 요청일까지로 밝힌다. 상대 날짜가 혼동될 수 있으면 절대 날짜를 쓴다.

## 증거 위계

1. 공식 플랫폼 도움말·정책·공식 리포트
2. 원문 학술 연구와 조사 방법이 공개된 보고서
3. 국내 기관·기업의 조사 원문
4. 원본 채널·영상 직접 관찰
5. 신뢰할 만한 인터뷰·보도
6. 공개 Agent Skill·크리에이터 실무 휴리스틱
7. 제3자 추정·블로그

하위 근거를 알고리즘 법칙처럼 쓰지 않는다.

## 라벨

- `FACT`: 출처가 직접 지지
- `INFERENCE`: 여러 사실을 제작 규칙으로 번역
- `HEURISTIC`: 테스트가 필요한 가설
- `UNKNOWN`: 공개 정보만으로 판단 불가

모든 한국 문화 규칙은 최소한 `INFERENCE`인지 `HEURISTIC`인지 밝힌다.

## 국내 조사 읽기

다음 항목을 확인한다.

- 조사 시점
- 표본 수와 모집 방식
- 연령 범위
- 질문 문구와 지표 정의
- 기업 자체 분류인지 학술적으로 검증된 척도인지
- 특정 세대의 평균을 개인 성향으로 오해할 위험

`디지털 얼리어답터`, `숏폼 네이티브` 같은 보고서 별칭은 설명용 세그먼트다. 사람의 본질적 정체성으로 사용하지 않는다.

## 학술 연구 번역

- 표본과 실험 조건을 말한다.
- 연구 주제 밖으로 일반화하지 않는다.
- 유의한 결과와 유의하지 않은 결과를 모두 본다.
- 상관관계를 인과로 바꾸지 않는다.
- 한 연구의 수치를 보편 임계값으로 만들지 않는다.

예: 운동 숏폼의 프레임 연구 결과는 `모든 한국 쇼츠는 긍정형이 낫다`가 아니라 `목표 유형과 프레임의 적합성을 검토한다`로 번역한다.

## 채널 벤치마크

### 수집

- 분석 시점과 공개 조회수
- 업로드 후 경과
- 영상 길이
- 주제·형식
- 첫 프레임·첫 말·자막
- 질문과 보상
- 화자 역할
- 유머·신뢰 신호
- 관계·공유 장면
- 반복 패턴

### 해석

공개 조회수가 높다고 모든 구성 요소가 우월하다고 결론 내리지 않는다. 채널 규모, 주제 수요, 검색·외부 유입, 업로드 시점, 기존 팬덤이 영향을 준다.

경쟁 채널의 다음 정보는 `UNKNOWN`이다.

- 실제 Stayed to watch
- 평균 시청시간·시청률
- 유지 그래프
- 정확한 공유 목적지
- A/B 테스트 결과

### 결과 표현

```text
관찰:
가능한 기능:
다른 설명:
새 채널에 적용할 원리:
복제하지 않을 표면:
검증할 실험:
```

## 공개 Agent Skills 검토

새로운 스킬은 스타 수보다 다음으로 평가한다.

- 도메인 적합성
- 지침의 구체성
- 출처와 데이터 공개 수준
- 과도한 성과 약속 여부
- 유지보수 상태
- 라이선스
- 한국 환경으로 이전 가능한 원리

### Vyral Content Skills

저장소는 20만 건 이상의 바이럴 TikTok·Reels·Shorts를 연구했다고 자체 설명한다. 공개 저장소에는 원본 데이터셋·표본 설계·분석 코드·독립 성능평가가 보이지 않으므로 이 수치를 독립 검증된 연구로 취급하지 않는다.

적극 채택:

- 다양한 훅 아키타입
- 시각·언어·자막 3층 훅
- Hook → Escalation → Payoff
- 약한 훅·상승 부재·묻힌 보상 진단
- 정확한 이탈 구간과 부분 재작성
- 바이럴 비보장 원칙

수정:

- 한국형 관계 층 추가
- 한 질문씩 creator-led 브레인스토밍
- CTA 의무 제거
- 한국어 화자 역할·전달 안전성·신뢰 부담 추가

제외:

- 공개 근거가 없는 고정 임계값
- 알고리즘 신호의 절대 순위
- 보편적 최적 길이·컷 간격
- 유료 서비스 홍보 지침
- 출처 없는 성과 향상 수치

## 최신성

플랫폼 정책·지표·유행어·밈은 빠르게 바뀐다. 패키지 내 사례는 영구 규칙이 아니다.

- 정책과 지표: 공식 출처로 재확인
- 유행어: 사용 시점·출처·집단 맥락 확인
- 문화 트렌드: 최근 원본 사례와 국내 조사 확인
- 대본 성과: 실제 채널 데이터가 최우선
