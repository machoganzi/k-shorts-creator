# SCRIPT — 한국형 YouTube Shorts 대본 설계

잠긴 Creative Brief를 우선한다. 사용자가 이미 훅을 확정했다면 임의로 교체하지 않는다.

## 훅

훅이 미확정이면 서로 다른 구조 3개를 먼저 설계하고 추천안을 고른다. 단어만 바꾼 변형은 다른 훅으로 세지 않는다.

각 후보에는 다음을 포함한다.

- 첫 프레임
- 첫 말
- 첫 자막
- 열린 질문 또는 이해관계
- 관계/감정 기능
- 최종 보상과의 일치
- 과장·모욕·광고 위험

## 제목 / 첫 화면 / 첫 말 분업

- 제목: 클릭 전 질문 또는 약속
- 첫 화면: 멈춰야 할 갈등·결론·장면
- 첫 말: 첫 화면을 확장하거나 뒤집는 정보

같은 문장을 세 번 반복하지 않는다.

## 30~50초 정보형 기본 골격

필요에 따라 변형한다.

`훅 → 자기대입 → 일부 보상 → 재해석/긴장 상승 → 핵심 원인·증거 → 최종 보상 → 자연스러운 루프 또는 단일 행동`

반전이나 CTA를 의무적으로 넣지 않는다. 반전은 실제 관점 변화가 있을 때만 쓴다.

## 출력

`../templates/shorts-script-template.md`를 참고해 초 단위로 작성한다.

각 비트에 최소 하나의 기능이 있어야 한다.

- 자기대입
- 초기 가치
- 질문 유지
- 원인·위험 상승
- 관점 전환
- 증거 제시
- 감정 보상
- 관계 연결
- 루프·단일 행동

기능 없는 비트는 삭제한다.

대본 작성 후 `references/korean-resonance-pass.md`와 `retention.md` 기준으로 자체 검수한다.
