# RESEARCH — 최신 조사와 벤치마크

`최근`, `오늘`, `지난 6개월`, 플랫폼 정책·지표·수익화, 법·의학·과학·금융·정치, 특정 채널 벤치마크는 저장소 지식만 믿지 말고 최신 공개 자료를 다시 조사한다.

## 증거 위계

1. 공식 플랫폼 문서·원문 연구
2. 조사 방법이 공개된 국내 조사
3. 원본 콘텐츠의 날짜가 확인되는 관찰
4. 신뢰할 만한 인터뷰·보도
5. 공개 Agent Skill·크리에이터 실무 휴리스틱

## 라벨

- `FACT`: 출처가 직접 뒷받침
- `INFERENCE`: 여러 근거를 제작 규칙으로 번역한 추론
- `HEURISTIC`: 실제 채널에서 시험해야 할 가설
- `UNKNOWN`: 공개 정보로 판단 불가

## 벤치마크 원칙

- 경쟁 채널의 비공개 리텐션을 안다고 말하지 않는다.
- 조회수·제목 관찰을 인과관계로 과장하지 않는다.
- 인트로·목소리·캐릭터·고유 문장·편집 서명을 복제하지 않는다.
- 기능(질문 구조, 압축, 시각 증거, 보상 순서)만 추출한다.

기존 근거는 `../references/evidence-register.md`를 출발점으로 쓰되, 날짜가 민감하면 최신 자료로 갱신한다.
