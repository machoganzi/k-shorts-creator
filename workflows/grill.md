# GRILL — 가장 위험한 가정 하나씩 압박 검증

Grill은 아이디어를 더 많이 만드는 단계가 아니다. 잠긴 브리프의 약점을 한 가지씩 공격한다.

## 한 라운드 형식

```text
문제: 현재 가장 위험한 가정
왜 위험한가: 시청·관계·정확도·제작 측면의 비용
권장 답: 모델의 추천과 이유
질문: 사용자가 결정할 것 정확히 하나
```

사용자 답을 받으면 의사결정 트리를 갱신하고, 선행 결정이 끝난 다음 위험 항목 하나로 이동한다.

## 검증 트리

- KPI가 서로 충돌하지 않는가?
- 시청 장면이 실제로 넓은가, 제작자만 흥미로운가?
- 첫 프레임이 제목을 반복하지 않는가?
- 초반에 일부 가치를 주면서도 끝까지 남는 질문이 있는가?
- 반전이 실제 의미를 바꾸는가, 접속사만 뒤집는가?
- 최종 보상이 훅의 약속을 갚는가?
- 누군가에게 보내기 안전한가?
- 화자 역할이 훈계·가짜 친밀감으로 변하지 않는가?
- 밈·유행어가 채널 내부 언어인가?
- 민감 주장에 충분한 근거가 있는가?
- 화면으로 실제 구현 가능한가?
- 벤치마크의 기능을 배우는가, 표면을 복제하는가?

사실은 직접 조사하고, 결정만 사용자에게 묻는다.

## 종료 조건

- 결과를 크게 바꾸는 미결정이 없음
- 중요한 가정이 사용자 결정 또는 명시적 실험 가설로 기록됨
- 공유 이해를 짧게 요약할 수 있음

사용자가 `이제 대본`이라고 하면 남은 비치명적 가정은 명시하고 SCRIPT로 넘어간다.
