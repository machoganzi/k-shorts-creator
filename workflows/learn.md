# LEARN — 실제 성과 데이터로 다음 가설 갱신

가능하면 다음을 받는다.

- 영상 길이
- 공개 조회수
- Engaged views
- Stayed to watch
- 평균 시청시간
- 평균 시청률
- 유지 그래프
- 공유, 댓글, 구독 전환
- 유입 경로
- 게시일

`../references/analytics-and-learning.md`와 `../templates/performance-review-template.md`를 사용한다.

## 원칙

- 공개 조회수 하나로 성공을 판정하지 않는다.
- 같은 채널의 비슷한 길이·주제·형식과 비교한다.
- 댓글에서 자기대입, 전달, 신뢰/불신의 질적 신호를 분리한다.
- Analytics에 없는 전달 목적지를 사실처럼 추측하지 않는다.
- 다음 영상에서는 한두 변수만 바꾸고 가설을 기록한다.

성과 복기는 `관측 사실 → 가능한 원인 → 반대 설명 → 다음 실험` 순으로 쓴다.
